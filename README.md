# Algorithmic Thinking: Temperature Analyzer

This project is part of Laboratory 01 for the Algorithmic Thinking module. It consists of a Java program that analyzes a dataset of temperatures recorded over exactly 30 days without using built-in sorting or math library functions.

## Features
- Validates the dataset strictly requires 30 records.
- Verifies temperature values fall within a realistic range (-50°C to 60°C).
- Calculates the maximum temperature, minimum temperature, and average temperature.
- Counts the number of days where the temperature exceeded the monthly average.
- Built with optimal Big O(N) complexity using exactly two sequential passes.

## How to run in Visual Studio Code
1. Make sure you have the **Extension Pack for Java** installed in VS Code.
2. Open the file `TemperatureAnalyzer.java`.
3. Click the `Run` or `Debug` button that appears above the `main` method, or press `F5`.
4. The output of the test cases (Normal case, Incomplete records, Out of range data) will be displayed in the terminal.
